# Шаблон дополнительной обработки для конфигруций 1с на основе БСП

## Ключевые возможности

- Интерфейс для управления настройками команд и обработки в целом. Поддерживает следующие типы:
  - Примитивные: Число, Строка, Дата, Булево
  - Ссылочные
  - Составной тип из ссылочных и примитивных типов
  - Массив для ссылочных и примитивных типов
  - Список значений для ссылочных и примитивных типов
  - Таблица значений с типизацией колонок
- Упрощение отладки при разработке, внедрении и эксплуатации. Достигается за счет:
  - Единого подхода к хранению и доступу к настройкам
  - Единая точка входа для отладки
- Логирование событий в журнал регистрации

## Порядок внедрения

### В режиме "1С:Конфигуратор"

1)	Изменить имя и синоним обработки. К имени обработки отнестить ответственно, дальнейшие переименования потребуют дополнительные действия по вводу параметров.
2)	В процедуре "СведенияОВнешнейОбработке" добавить необходимые команды    
3)	В процедуре ВыполнитьКоманду описать реализацию выполнения команд из пункта 2)
4)	(Необязательный) Добавить необходимы параметры в процедурах:
			- ЗагрузитьНастройкиОбработкиПоУмолчанию  - содержит параметры, которые относятся к обработке в целом
			- ЗагрузитьНастройкиОбработкиБезопасноеХранилищеПоУмолчанию  - содержит "чувствительные" параметры, 
				которые относятся к обработке в целом
			- ЗагрузитьНастройкиКомандыПоУмолчанию  - содержит параметры команды
			- ЗагрузитьНастройкиКомандыБезопасноеХранилищеПоУмолчанию  - содержит "чувствительные" параметры команды  
В процедуре "ЗагрузитьНастройкиКомандыПоУмолчанию" приведены различные примеры параметров для разных типов

### В режиме "1С:Предприятие"

1) Загрузить обоработку в справочник "ДополнительныеОтчетыИОбработки". 
2) Переоткрыть обработку. Реквизит "Дополнительная обработка" заполнится ссылкой на обработку из пункта 1). Сопоставление идет по имени обработки.
3) Заполнить значения для параметров для обработки и команд и сохранить. После сохранения нужно Обязательно переоткрыть обработку
4) (Необязательный) Для команд настроить расписание
